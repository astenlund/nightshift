What does a blocked stop cost?

Each block is another model turn with the whole conversation as input. For the same work in step 2's rehearsal:

22 turns

with the first guard

14 turns

with the three-reminder rule

Costs grow fastest when a guard never lets go, when the context is large (compaction itself reads all of it), and when a goal adds a small-model call to every turn.

Step 6 · Questions

What happens when Claude needs to ask me something?

In a reply

The turn ends, so the Stop hook decides. A hook never pauses itself, so there is nothing to switch back on. /goal pushes back until met, judged impossible or capped, then stays set.

In the question dialog

The turn stays open: no hook runs, and by default it waits for an answer. Fix it with askUserQuestionTimeout, or a PreToolUse hook that refuses the dialog during a handover.

Permission prompts, including plan approval, never time out. Give an unattended run the permissions it needs before you leave.

Stop Guard Cook-Along · Questions · The hook's code and settings block: guide, Questions

Rehearsed interactively: the dialog sat unanswered for four minutes during a handover; with a 60-second timeout a countdown appeared and Claude parked the question; with the PreToolUse hook Claude parked it and the guard paused ten seconds later. The timer does not count down while the terminal window is focused and never starts in a background session or with Remote Control connected. Headless claude -p runs offer the dialog only when they have a permission host to answer it.

Why a Markdown file, and not a database or Claude's own to-do list?

The record must be readable by the hook without trusting the conversation, readable and editable by you, and outlive the session. A file in the repository does all three, and shows up in a diff. It stops being enough when:

  • several agents or sessions write to it at once
  • you need history or evidence, such as which check proved a task done
  • an agent should not be able to rewrite it freely

Those are the reasons I gave Nightshift a database, changed only through checked operations.

What happens if the hook crashes?

It fails open: Claude stops as if the hook were not there.

  • Rehearsed: TASKS.md deleted, the guard threw, Claude Code reported a non-blocking hook error.
  • The same for node missing from the path, output that is not valid JSON, or a run past the 600-second timeout.
  • Only exit code 2 blocks; a crashing Node script exits with 1.

I made Nightshift's hook fail open too: whether a run is complete is decided from recorded evidence, never from the fact that Claude stopped.

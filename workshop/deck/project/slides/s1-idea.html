Step 1 · The idea

Stop is the moment the work can be checked

1 · The event

Claude is about to end its turn, so Claude Code fires Stop.

2 · Your command

It gets the event as JSON on stdin and answers on stdout.

3 · The answer

A block with a reason sends Claude back to work. Nothing ends the turn.

The hook does not ask Claude whether it is done. It looks at the record.

Why I chose this for Nightshift

When I hand work over to Nightshift on Claude Code, a Stop hook like this keeps Claude working until the run is done. Codex models tend to end their turn early, so on Codex I rely on its own persistent goal instead.

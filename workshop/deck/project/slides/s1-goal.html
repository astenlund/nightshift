Step 1 · Likely question

Why not just type /goal?

Often you can. /goal is this same mechanism, built in: a session-scoped Stop hook, where a separate small model judges your condition from the conversation after every turn.

/goal fits when

  • the work fits one session
  • "done" is something Claude can show, like a passing test run
  • you want another model to judge it

A hook and a record fit when

  • the rule holds in every session, for everyone
  • "done" is read from a file or a command
  • you need your own exit rules

In rehearsal, /goal looped nine times on a task only the user could do.

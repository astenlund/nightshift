Does this carry over to Codex?

The idea does; the mechanism depends on the host. For Nightshift I use Codex's own persistent goal there, because Codex models tend to end their turn early, and the Stop hook on Claude Code.

When the agent stops to ask

In my Nightshift runs on Codex, a goal that is paused or blocked while the agent waits stays that way after Nightshift picks the run up again, until I reactivate it. Whether Codex pauses it or Nightshift has to block it is not settled yet.

On Claude Code a hook has nothing to resume, and a /goal stays set.

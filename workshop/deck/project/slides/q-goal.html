Step 6 · Questions

Why not just set a goal with /goal?

Choose /goal when

  • the work fits one session
  • "done" can be shown in the conversation, like a passing test run
  • an unfinishable task is unlikely, or the way out is in the condition
  • you would rather write a sentence than code

Choose a hook and a record when

  • the rule must hold in every session, for everyone
  • "done" is read from a file or a command
  • exit rules must behave the same every time
  • the list must outlive the conversation and the session

They combine: a goal and your hooks run side by side. Nightshift needs everything on the second list, which is why it uses a Stop hook and its own record.

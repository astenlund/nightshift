A permission mode decides whether Claude may act without asking. The guard decides whether it may stop.

"Auto mode on its own approves tool calls within a single turn but doesn't start a new one."

An unattended run needs both. In rehearsal, a permission prompt for a sed command held a run just like an unanswered question.

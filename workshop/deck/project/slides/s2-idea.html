Step 2 · The idea

Three ways to let go

Check stop_hook_active

One nudge, ever, even while Claude is doing real work.

Lean on the cap

Nine blocks in a row, then Claude Code overrides you. Late, and silent about what is unfinished. /goal ends up here too.

Count reminders without progress

Any change to the record resets the count. After three with nothing changed, stop and say what is unfinished.

Stopping only beats looping if the stop says what is unfinished. And a guard that never lets go pushes an agent toward actions nobody authorised: imagine the stuck task was "Publish the package to npm".

Why I chose this for Nightshift

Nightshift uses the third way: the run stops and is reported incomplete, never done. It also asks before destructive, irreversible or outward-facing actions I haven't authorised, and parks them when I'm away.

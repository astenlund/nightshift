Step 3 · Likely question

What if Claude asks with the question dialog instead?

The multiple-choice dialog keeps the turn open, so no Stop hook runs, and by default it waits until someone answers. Fine while you are at the keyboard. In rehearsal, during a handover, it sat unanswered for four minutes.

Let it time out

askUserQuestionTimeout: 60s, 5m or 10m. It does not count down while the terminal window is focused, and never starts while Remote Control is connected.

Refuse it while you are away

A PreToolUse hook denies the dialog during a handover. Claude parked the question, and the guard paused ten seconds later.

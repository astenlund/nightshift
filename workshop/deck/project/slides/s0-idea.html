Step 0 · The idea

Models judge, code keeps the books

Leave engineering and product judgment to the model. Give the bookkeeping to plain code wherever a mistake would lose work, corrupt state or misreport what happened.

Hooks are where that split lives in Claude Code: your own program, run by the harness at a fixed moment. Claude cannot skip it; it can only decide what to do with the answer.

Why I chose this for Nightshift

Nightshift carries agreed work through implementation, review and verification while I sleep. I can't check on the model at 3 a.m., so the bookkeeping that decides whether a night's work counts as done lives in code the model can't skip.

Not every feature has a moment in one night

These run too: in setup, on the platform, in packaging and release, in verification, and in other ways of working. None of them needed a beat in tonight's run.

Setup and backlog tooling

  • Setup finds your instruction files and routes backlog guidance to them.
  • Setup proposes repairs for customized backlogs and legacy guidance.
  • Ready, setup and unwrap share one backlog parser and vocabulary, keeping the grammar differences that have a reason.
  • A fresh project chooses to track, ignore or defer its backlog.
  • You choose shared .gitignore rules or clone-local excludes.
  • Mixed line endings in the backlog are repaired under inspection.

Windows platform and runtime

  • File metadata that matters is kept through writes and recovery, or its limits are stated.
  • Setup recovery touches only files it provably owns.
  • Every launched executable, Git included, has its identity verified.
  • Request files and review copies are protected before anything sensitive is written.
  • Host transports stay bounded, and every timer has one owner.
  • Malformed host events are handled without weakening model checks.
  • Review content is captured once per operation.

Packaging and release

  • The installed package holds what runs and your docs, leaving out maintenance material where the host allows.
  • The release gate tells a stale branch from a real version decrease.
  • Run-time guidance lives apart from design reference material.

Verification and measurement

  • Verification evidence and fixtures have owners and safe storage.
  • A seeded-defect suite measures how often the lifecycle catches bugs.
  • Lead agent overhead is measured before any saving is claimed.
  • Command restrictions you set are enforced where they matter.

Other ways to work

  • Revise can run on its own, outside any run.
  • Review mode checks someone else's branch or pull request.
  • A whole-backlog audit checks every entry against the code.
  • Codex and Claude Code sessions pair up in visible panes.
  • The graphical run view shows a run like this one, live.

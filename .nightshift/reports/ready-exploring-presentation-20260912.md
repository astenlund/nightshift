## Limits and outstanding work

These probes supplied candidate skill text and real parser output over synthetic fixture backlogs to installed CLI hosts. The explicit payload omitted personal and project instruction files, but the hosts were not isolated from all installed context. Every Codex probe listed the personal `.codex/AGENTS.md` as an instruction source, and every Claude probe listed installed plugins including Nightshift 3.0.10 and agent-hooks 1.1.0. Those metadata do not establish actual instruction injection or hook execution. The probes establish presentation behavior under the observed host conditions; they do not establish candidate marketplace activation or behavior with a verified isolated instruction context. Source-link checks establish valid Markdown destinations and file existence, not UI click handling. The tests are observations of model behavior, not a guarantee of identical future responses.

The original presentation work passed the real repository parser, backlog line check, tracked-file line-ending gate and diff whitespace check. Packaging then had four passing tests and one failure: the shared README status expression required an unpublished candidate to claim publication. The user initially directed tracking that defect, then authorized its repair during subsequent release preparation. The gate now accepts truthful candidate and published declarations while preserving version checks; the fixed defect is recorded in BUGS_HISTORY.md. Missing continuation tracking remains recorded for separate reconciliation and was not repaired here.

# Handover

Read [the shared operating brief](../../internal/workflow.md) and [the runtime interface](../../internal/runtime/REFERENCE.md). Carry the authorized work through implementation, independent assurance, verification, documentation, retrospective and follow-up triage. Autonomy comes first, independent quality second, efficiency third, within user limits.

Establish the agreed commitments, authority, dependencies, actual state and valid evidence. Preserve existing agreement and completed work; do not replay confirmation because the session compacted or a compatible spec correction landed. New work needs the investigated readback or concise-spec agreement described in the brief. Before the user leaves, settle known user-owned decisions and verify essential execution, review and continuation capabilities.

Create or reconcile the durable finite queue before implementation. Set the native persistent goal to continue through the agreed lifecycle until verified completion, an explicit stop/limit, or no remaining actionable authorized work or recovery. Verify native continuation and bundled hook readiness on the actual host. After yields and compaction, reconcile state, files and surviving workers before dependent actions. Use status at consequential boundaries, preserve write ownership, and work through recoverable failures instead of ending the run.

Implement directly with a strong model. Use bounded helpers and optional lower-tier supervision where authorized and useful; keep consequential judgment and acceptance. Prefer equivalent-strength review on the other host when suitable, with fresh same-host review valid. A routine plan is not part of this lifecycle.

Every finding needs fresh skeptic validation; every repair needs relevant checks and cumulative strong broad review. Continue independent tasks when an item is blocked. Finish with documentation and backlog, then retrospective, then the existing one-at-a-time follow-up triage. Preserve unanswered follow-ups when the user is unavailable. Local commits follow policy; publication requires authority and the applicable review gate. Report incomplete obligations explicitly.

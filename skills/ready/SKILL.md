# Ready work

Run the bundled ready.js with the absolute project root, or its .nightshift directory, as the argument. It returns ready, blocked, external and exploring work plus structural errors and notices. Report parser failures as failures, not an empty or clean backlog.

Present the ready set with concise context and dependencies. Keep blocked/external work distinguishable and Exploring drafts out of the ready set. Inspect linked source entries when recommending priorities, using the user goals and the invariant order of autonomy, quality and efficiency. Readiness does not authorize implementation: do not implement a recommendation on your own. Close the report by inviting the user to name the items to hand to handover, phrased as a colleague's offer rather than a restatement of this constraint, which is guidance for you and not for the user.

After a backlog edit, run this actual parser again to verify its grammar and dependency references. This skill is read-only unless the user separately authorizes an edit.
